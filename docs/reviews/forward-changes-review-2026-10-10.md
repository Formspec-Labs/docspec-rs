## Patch summary

The patch adds a local `ForwardChanges` comparison path. It walks exact co-committed certificates backward from the requested after version, verifies continuity to the requested before version, then streams signed removed/added relations into the existing comparison normalization. Missing/retired optional history, unsupported groups, reverse/unrelated states, and declared history limits retain full comparison. Present invalid evidence produces an error.

The implementation reuses local certificate checks, the native selected reader, DataFusion relational operators, and futures sequencing. It introduces a small `PartitionStream` adapter rather than another execution engine or persistent index. Full and accelerated paths share `signed_frame` and occurrence-first normalization.

## Data flow and invariants

**Local authority is explicit.** A matching descriptor file alone grants no authority. The certificate must match its exact selected result and native commit revision. Its before reference resolves through the same captured catalog rows; each predecessor revision must decrease. Each source delta binds the selected predecessor/current physical source metadata. Receipt-only hops must preserve logical source metadata. Both requested canonical endpoints are checked. These rules prevent a copied certificate, inconsistent predecessor, or receipt-only source change from being treated as an empty transition. [certificates.rs:127](/Users/mikewolfd/Work/spicy-stack/docspec-rs/src/engine/changes/certificates.rs:127), [chain.rs:82](/Users/mikewolfd/Work/spicy-stack/docspec-rs/src/engine/comparison/chain.rs:82), [chain.rs:144](/Users/mikewolfd/Work/spicy-stack/docspec-rs/src/engine/comparison/chain.rs:144)

**Availability and history stay separate.** Endpoints require available retained releases. Intermediate source identities come from retained catalog result records without reopening intermediate complete manifests or payloads. A retired intermediate result can therefore remain part of a valid optional chain; retiring its certificate instead selects full comparison. Active certificate bytes that disappear or change produce an error through `read_manifest`, not silent fallback or empty output. This respects R4/R6's independent state and acceleration lifetimes. [chain.rs:98](/Users/mikewolfd/Work/spicy-stack/docspec-rs/src/engine/comparison/chain.rs:98), [certificates.rs:172](/Users/mikewolfd/Work/spicy-stack/docspec-rs/src/engine/changes/certificates.rs:172), [inputs.rs:399](/Users/mikewolfd/Work/spicy-stack/docspec-rs/src/engine/inputs.rs:399)

**Signed composition preserves endpoint meaning.** Every qualified removed relation has weight −1 and added relation +1. Exact intermediate occurrences cancel algebraically. The shared addressed comparison first groups by visible values plus occurrence address, then performs value-only cancellation if requested. Counts use the same chosen identity. Metadata effects still derive from the requested endpoints. Native delta schema/default rules must match the endpoint rules; no casts or schema reconciliation are introduced. **The resource limits are real admission limits, not throughput evidence.** The production link cap bounds empty/tiny transitions; the cumulative serialized-byte check includes selected result records, certificates, descriptors, and delta table metadata. Decoded descriptors/native metadata receive separate shared-memory reservations. The returned sequence owns those reservations and the DataFrames. Reader inventories and batches open one child at a time; underlying native readers retain their usual metadata and batch checks. Dropping the returned engine stream releases its shared maintenance admission and prevents later children from opening. Blocking descriptor parsing retains its admission even if its async caller is canceled.
