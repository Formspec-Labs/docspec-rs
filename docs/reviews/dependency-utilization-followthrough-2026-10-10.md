## Why the remaining custom code is appropriate

Dataset selection binds related snapshots, evidence and completed work; native Iceberg commits and expiration do not decide those cross-table lifetimes. Stable occurrence addresses and complete-file checks preserve original interpretation through rewrites; blindly pushing filters below them can change positions or coverage. Application permits cover decoder, metadata and outgoing-chunk lifetimes outside the query pool, including work that survives caller cancellation. These are required domain and ownership checks around maintained components, not substitute database, decoder, scheduler or HTTP implementations.

The next useful work is narrow call-site improvement and controlled evidence for the outstanding candidates. This audit establishes package coverage and current API facts. It establishes no new speedup, whole-process memory bound, disk saving or hosted qualification.
